# xskii4 Phonetic & Barakhadi Rules

## Core Alphabet Rules
- **Lowercase Only (`a-z`):** Capital letters `A-Z` are remapped to symbols and punctuation in `xskii4`.
- **24-Letter Set (No `j` or `q`):** Mirrors the 118 IUPAC chemical element symbols, which never use `J` or `Q`. `z` handles ज/j sounds (`zh` for झ).
- **Consistent Vowels:**
  - `x` = **अ** (pure short vowel, e.g., *xnar*, *xmerika*; never `/ks/`)
  - `a` = **आ** (e.g., *aam*, *always*)
  - `e` = **ए / ऐ** (e.g., *epple*)
  - `i` = **इ / ई**
  - `u` = **उ / ऊ**
  - `o` = **ओ / औ**

## The `v` (`∀`) vs. `h` Rule
- **`v` (rendered as `∀`, `U+2200`):** Visually mirrors `H` and represents the standalone **ह (`/h/`)** sound (e.g., `vorse` = *Horse*, `vot` = *Hot*).
- **`h`:** Reserved strictly for aspirated consonants (`kh`, `gh`, `ch`, `zh`, `th`, `dh`, `ph`, `bh`, `sh`, etc.).
- **Clean Combinations:** Sonorants (`n, m, y, r, l`) and labials/fricatives (`w, f, v`) omit `v` (`∀`) combinations, and the standalone `v` row omits `vv` and `vh`.
